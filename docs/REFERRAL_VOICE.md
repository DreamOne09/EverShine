# 引薦案例怎麼寫，才不像 AI

官網案例是會員在例會講出來的話，不是教材金句。整理進網站時，只做去識別化、錯字、長度，**不要重寫成一課「什麼是好引薦」**。

## 聽起來像人的

- 有現場：老公寓、跳電、罰款期、見了兩次面
- 有稱呼：智威兄、沛璇姊、林師傅
- 句子長短不一，甚至有點囉嗦
- 結果講得出來：50 萬、第三刷、兩個案場
- 結尾常常是「謝謝 XX，也謝謝 BNI」

## 聽起來像 AI 的（不要）

- 「不是 X，是 Y」
- 破折號金句（——）
- 教訓句：引薦不是當天就要單／不要把客人吃乾抹盡／這就是協力團隊
- 抽象詞：信任網絡、成交週期、財務彈性、大幅改善
- 英文行銷詞硬塞：長期 B2B、Power Team（會員自己講的除外）
- 引薦人、被引薦人、摘要三句在複誦同一句 slogan

## 摘要（highlight）怎麼寫

從故事裡抽出**一件具體的事**，不要另寫金句。

- 好：太太公司的展場案，兩次見面成交 50 萬。
- 不好：信任網絡加上快速回應：不是「再約下次」，是兩次會議就收案。

## 流程

1. 先貼會員原話（例會紀錄／wiki／本人提供）。
2. 只改客戶品牌去識別化（見 `src/data/referral-brand-replacements.json`）。
3. 摘要用原話裡的事實，不新編道理。
4. 不確定的數字、保單名、客戶稱呼：放 `scripts/referrals_pending_confirm.json`，不要猜。
